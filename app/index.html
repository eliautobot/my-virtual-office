Agent browser

Give your agents a real web browser they control while you watch in a live viewer window. Agents drive it with the Chrome DevTools Protocol (CDP); the viewer is any VNC, noVNC or web view of the same browser. Works with KasmVNC, headless Chromium, browserless.io, Playwright or any setup that exposes CDP.

Usually on the same machine as the office. Use 127.0.0.1 when the browser container is local.

Loads in the floating browser window, so it must be reachable from your device (not localhost when you open the office remotely). Plain HTTP avoids certificate warnings.
