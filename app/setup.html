3. AGENT BROWSER (OPTIONAL)

Connect a browser so your agents can browse the web and you can watch live. You can skip this and set it up later.
The address where Chrome/Chromium remote debugging is running.
The live browser view (KasmVNC, noVNC, etc.) shown in the floating browser window.
What is this? The Agent Browser gives your AI agents a real web browser you can watch live. You need two things:

1. CDP (Chrome DevTools Protocol): how agents control the browser
2. VNC Viewer: how you watch the browser live in the office

Easiest setup, one Docker command:
docker run -d --name vo-browser -p 9222:9222 -p 6902:6902 -p 6901:6901 kasmweb/chromium:1.17.0

This gives you CDP URL http://127.0.0.1:9222 and Viewer URL http://127.0.0.1:6902.

Or use your own Chrome + VNC: google-chrome --remote-debugging-port=9222 --user-data-dir=/tmp/vo-browser, then point Viewer URL to your VNC/noVNC server.

Not sure? Skip this step; everything else works without it.

4. SMS PANEL (OPTIONAL)

Let an AI agent send and receive SMS messages through your office. You can skip this and set it up later.
This agent owns the Twilio inbox and is the default AI responder for every contact thread.
All three Twilio fields are required for sending SMS.
What is this? The SMS Panel lets you send and receive text messages through an AI agent in your office.

What you need: a Twilio account (free trial works), a Twilio phone number, and your Account SID and Auth Token from the Twilio Console.

Photos and attachments: incoming MMS media shows in the SMS inbox. Sending attachments needs a public HTTPS media URL that Twilio can fetch; text-only SMS works without it.

Not sure? Skip this step; you can enable it later in Settings.

5. PC PERFORMANCE (OPTIONAL)

Show a computer's CPU, RAM, and GPU use live in your office dashboard. You can skip this and set it up later.
The address where the PC Metrics Server runs, on this machine or another one.
How it works: run a small Python script on the computer you want to watch. It shares its stats on a port, and the office reads them.

On that computer: pip install psutil then python pc-metrics-server.py 8099. The script ships with Virtual Office at /app/pc-metrics-server.py.

For NVIDIA GPU stats: pip install pynvml

URL examples: same machine http://127.0.0.1:8099, another computer on your network http://192.168.1.100:8099.
